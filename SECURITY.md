# Security

Auralis runs entirely on-device and sends no audio or text to any service. The only network access is downloading speech models from Hugging Face and, when you run it, the optional local `auralis-server`, which binds to `127.0.0.1` and has no authentication.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Include steps to reproduce and the affected version.

We aim to acknowledge reports within a few days and will credit reporters who want it.
