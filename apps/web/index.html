How it works

A reusable Rust pipeline, driven by a tray-only desktop shell.

Capture & resample

Default input device via cpal, mixed to mono and resampled with a sinc interpolator to the rates each stage needs.

Voice activity detection

webrtc-vad trims leading and trailing silence, and segments continuous speech into utterances on a trailing-silence boundary.

Denoising

RNNoise via nnnoiseless — pure Rust, no native dependency, operating on the same 10 ms frames as the VAD.

Transcription

whisper.cpp through whisper-rs on quantized GGUF weights. Beam search with temperature fallback, and no_context to suppress repetition loops.

Text intelligence

Local rules only — capitalization, terminal punctuation, conservative disfluency removal, and a spoken-correction heuristic.

Insertion

Simulated keystrokes via enigo, with a clipboard fallback. The app never takes focus, so keystrokes land where you were typing.

The pipeline lives in runtime/core as a standalone library, independent of the desktop shell — so it can be driven by a benchmark runner or another front end.

Text cleanup modes

How much the text layer is allowed to rewrite what you actually said.

raw is always available, so a transcript can be inspected with no rules in the way. developer exists because dictating a shell command should not acquire a trailing period. Disfluency matching is deliberately conservative — only tokens that are not also ordinary English words, so “summary”, “ahead” and “error” survive while a standalone “um” does not.

Status

What exists today, and what deliberately does not.

Phase 1 — vertical slice

  • Mic capture, resampling, VAD trimming, RNNoise denoising
  • whisper.cpp transcription and local text cleanup
  • Tauri desktop app, global hotkey, keystroke injection
  • Manual end-to-end verification on a live microphone

Phase 2 — measurement

  • WER / CER / RTF benchmark harness with a CLI runner

Phase 3 — dictation UX

  • Continuous / toggle dictation via VAD stream segmentation
  • Tray icon, settings window, persisted configuration
  • In-place spoken correction of already-inserted text
  • Text cleanup modes and audio quality analysis

Phase 4 — shipping

  • Continuous integration, brand assets, STT accuracy pass
  • Windows installer built by release automation; models download on first launch
  • GPU build switches for CUDA and Vulkan — the CPU build needs no toolkit
  • Local transcription API: POST /v1/transcriptions
  • Code-signed installer — pending a signing certificate

No benchmark numbers are published yet. The harness exists and measures WER, CER and real-time factor across model size, preprocessing variant and dataset — but running it on a real corpus is still outstanding, so there is nothing honest to quote here. Accuracy claims will arrive with the commands used to produce them.

Download

Windows 10 and 11. Free and open source.

Download installer
Latest release on GitHub
  1. Run the installer. It installs for your user and needs no administrator rights.
  2. Auralis starts in the system tray and downloads its speech model (about 59 MB) on first launch.
  3. Hold Ctrl + Space in any app, speak, release.

Windows may show a SmartScreen warning. Installers are not code-signed yet, so choose “More info” then “Run anyway”. You can verify what you are running — the installer is built from this repository by a public workflow, and every line is open to inspect.

Build from source

For contributors, or to run the latest commit.

# Clone and fetch a model
git clone https://github.com/Sagexd08/Auralis
cd Auralis
powershell -File models/pull-model.ps1          # base.en  (~59 MB)
powershell -File models/pull-model.ps1 small.en # better accuracy, ~3x decode cost

# Rust library and tests
cargo test -p auralis-runtime

# Desktop app
cd apps/desktop
npm install
npm run tauri dev

Requires Rust (stable, x86_64-pc-windows-msvc), Node.js, CMake, and a libclang compatible with bindgen 0.69 — whisper.cpp is compiled from source. A CUDA Toolkit is only needed for GPU acceleration. See the repository README for the libclang version caveat.
