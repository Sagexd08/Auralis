Instant transcription

Dictation that never leaves your PC.

Auralis types what you say into whatever window has focus: your editor, a terminal, a chat box, a form. Hold a key, speak, let go. Audio is captured, cleaned and transcribed on your own machine by whisper.cpp. There is no cloud speech service, no cloud text cleanup and no telemetry.

It is open source under the MIT license, built as a Rust runtime with a small Tauri shell, and installs as a single Windows installer.

Install

  1. Run the installer and launch Auralis.
  2. Wait for the first-run model download (about 59 MB).
  3. Click into any text field, hold Ctrl+Space, speak, release.

Releases are not guaranteed to be code-signed. If Windows SmartScreen warns you, check the file against the release page before choosing to run it.

Build from source

git clone https://github.com/Sagexd08/Auralis
cd Auralis/apps/desktop
npm ci
npm run tauri build

# GPU: add --features cuda
# or    --features vulkan

Use the local API

auralis-server --model base.en.bin

curl -X POST \
  "http://127.0.0.1:8787/v1/transcriptions?cleanup=clean" \
  --data-binary @speech.wav

WAV in, JSON out: text, duration, processing time, model.
