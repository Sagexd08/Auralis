Six stages, all local.

Audio never leaves the machine. Each stage is a small, replaceable part of an open Rust runtime.

IN
Mic
cpal, default or chosen device
TRIM
VAD
drops leading and trailing silence
CLEAN
Denoise
RNNoise, pure Rust
SPEECH → TEXT
Whisper
whisper.cpp, quantized weights, beam search with temperature fallback
RULES
Cleanup
four modes, spoken corrections
OUT
Insert
keystrokes, clipboard fallback

Hold or tap

Hold Ctrl + Space for push-to-talk. Tap Ctrl + Shift + Space for hands-free dictation that splits on pauses.

Fix it by voice

Say “actually, change Rahul to Rohan” and Auralis backspaces what it typed and retypes the corrected sentence. Corrections expire after 45 seconds so they never eat unrelated text.

Pick your accuracy

Start with the 59 MB base model. Switch to small or medium in Settings for better names and accents, at a higher CPU cost.

You choose how much it rewrites.

Four cleanup modes, switchable at any time. Raw shows exactly what the model heard.

MODEWHAT IT DOES“uh git checkout main” BECOMES
rawNothing. The model’s output, trimmed.uh git checkout main
cleanCapital letter and a terminal mark.Uh git checkout main.
polishedClean, plus drops “uh”, “um”, “erm”.Git checkout main.
developerDrops fillers, adds no capital or period.git checkout main

Real rules from the text layer. Words like “like” and “so” are never removed.

Use it from anything.

The same pipeline runs as a local HTTP server. Send a WAV file, get text back. It binds to loopback only and has no authentication, so it stays on your machine.

$ auralis-server --model models/ggml-base.en-q5_1.bin

$ curl --data-binary @meeting.wav \
    -H "Content-Type: audio/wav" \
    "http://127.0.0.1:8787/v1/transcriptions?cleanup=clean"

{ "text", "duration_s", "processing_s", "model" }

Download Auralis.

Windows 10 and 11. Free, open source, and nothing to sign up for.

Download installer Latest release on GitHub
  1. Run the installer. It installs for your user and needs no administrator rights.
  2. Auralis starts in the tray and downloads its speech model, about 59 MB, on first launch.
  3. Hold Ctrl + Space in any app, speak, release.

Windows may show a SmartScreen warning. Installers are not code-signed yet, so choose “More info”, then “Run anyway”. The installer is built from this repository by a public workflow, and every line is open to inspect.

Build it yourself.

For contributors, or to run the latest commit. Needs Rust, Node.js 20+, CMake, and a libclang that works with bindgen 0.69, because whisper.cpp is compiled from source. The README covers the libclang caveat.

git clone https://github.com/Sagexd08/Auralis
cd Auralis
powershell -File models/pull-model.ps1

cargo test -p auralis-runtime -p auralis-desktop

cd apps/desktop
npm install
npm run tauri dev
