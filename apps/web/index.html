FRAME 01 / 08The paywall

I wanted Wispr Flow. I couldn't pay for it.

Dictation that types into any app, anywhere, is a subscription. I had a keyboard, a microphone and a free weekend, so I decided to build the thing I couldn't buy.

FRAME 02 / 08One key

The whole idea fits on one key.

Hold Ctrl+Space and talk. Let go and the words are in the window you were already using. Nothing to open, nothing to switch to. Move over the keys to press them.

FRAME 03 / 08Make it listen

A tray app that hears you.

Rust and Tauri on Windows. A global hotkey starts the microphone; releasing it stops. The audio stays in memory on your own machine while it is turned into text.

  • Rust
  • Tauri 2
  • global hotkey

FRAME 04 / 08Make it understand

Five small steps from sound to text.

Voice activity detection trims the silence. RNNoise takes out the hiss. whisper.cpp does the transcribing, on your own processor. A few local rules tidy the punctuation.

  • mic
  • vad
  • denoise
  • whisper.cpp
  • cleanup

FRAME 05 / 08Make it type

Into whatever window has focus.

The text arrives as keystrokes, with a clipboard fallback. Say “actually, change Rahul to Rohan” and it backspaces what it just typed and fixes it in place.

  • any app
  • spoken corrections

FRAME 06 / 08Keep it yours

No cloud. No account. No telemetry.

The model is a file on your disk. The little server I ship only listens on localhost and refuses other websites unless you explicitly allow them.

  • on-device
  • MIT licence

FRAME 07 / 08Everything that broke

It broke in boring ways.

A model download link that returned 404. A CI linter newer than the one on my laptop, failing pull requests that passed locally. A browser that will not let a website talk to localhost until you say yes. Each one taught me something I'd have skipped.

  • 404
  • CI lint
  • local network access

Auralis · Whitepaper · Phase 1

Local-first push-to-talk dictation

Auralis turns speech into typed text in any Windows application. Every stage, from microphone capture to keystroke injection, runs on the user’s own machine. No audio or text is sent to a cloud service, and the software collects no telemetry.

Questions

What is Auralis?
Open-source, push-to-talk dictation for Windows. You hold Ctrl+Space, speak, and release, and cleaned-up text is typed into whatever app has focus.
Does Auralis send my voice to the cloud?
No. Speech recognition runs on your own PC using whisper.cpp. There is no cloud speech-to-text, no cloud text cleanup and no telemetry.
What is the keyboard shortcut?
Hold Ctrl+Space to talk and release to insert the text. Press Ctrl+Shift+Space for hands-free continuous dictation.
Which apps does it work in?
Any Windows app with a text field. Auralis types into the focused window and falls back to the clipboard if that window blocks input.
Is Auralis free?
Yes. It is free and open source under the MIT license.
How big is the speech model?
The installer bundles OpenAI's Whisper base.en (about 59 MB) as an interim third-party default; Auralis' own models are in development. The optional small.en is about 190 MB and is more accurate on proper nouns and accents. Models are local files, and the app never downloads them.
